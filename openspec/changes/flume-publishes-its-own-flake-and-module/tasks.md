# Tasks

The groups are headings for reading. Each task names the narrowest check
that shows it done, run as written. No task runs the repository's whole
checks or a group's: the change's verify stage and the merge queue run
those (record 0054). `<base>` is the branch this place was cut from and
lands on, as CLAUDE.md's Checks has it.

agentplot/boomdrive's `nix/`, at its main on the host
(`~/Code/boomdrive/agentplot/boomdrive/nix/`), is the working model the
design cites as "Boomdrive's". Read its file before writing the one a
task names. nix reads a git tree's tracked files only, so stage each new
file under `nix/`, `flake.nix` and `flake.lock` (`git add <paths>`)
before a nix command reads it. Hashes and `flake.lock` are taken outside
the sandbox, in the devenv shell. Tests reach no account, no network and
no home but a scratch one.
