# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on main and on the
groups before it. A group's last task runs the checks it touched
through sluice. Every conformance scenario a group adds cites its
clauses as data (106). The engine's scenarios name no program: the
fake's `agent` and `other` stand for Claude Code and Codex (core.1).
Tests reach no real account and no configuration directory of the
user's. Every git call in a test runs under the scratch environment
`crates/flume/tests/common` gives. An agent in a test is the stand-in
(`crates/flume/tests/profiles/stand-in/`) or the fake, and every host
configuration, state directory and `CLAUDE_CONFIG_DIR` a test names is
a scratch one of the test's own.
