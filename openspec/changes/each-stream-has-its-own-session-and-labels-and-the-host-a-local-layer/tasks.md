(proposal, design, specs) and its group, and builds on the groups
before it. Work starts on main once the user has accepted records 0031,
0032 and 0033 and the change `an-intents-affinity-is-kept-per-program`
has landed, since both change `room.rs`, `start.rs` and the clause
list. A group's last task runs the checks it touched through sluice.

(106). Tests reach no real account, no herdr session of the host's and
no configuration directory of the user's: every `XDG_CONFIG_HOME`,
`config.toml` and `config.local.toml` a test names is a scratch one of
the test's own, every herdr session home the run's own scratch, or the
temporary folder run directly (design 2), and every git call runs under the
scratch environment `crates/flume/tests/common` gives.
