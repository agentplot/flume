# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on the tree at
f29f182. A group's last task runs the checks it touched through sluice;
every conformance scenario a group adds cites its clauses as data
(106). Tests reach no real credential and no configuration directory of
the user's: every git call in a test runs under the scratch environment
`crates/flume/tests/common` gives, and an agent in a test is the
stand-in (`crates/flume/tests/profiles/stand-in/`) or the fake.
