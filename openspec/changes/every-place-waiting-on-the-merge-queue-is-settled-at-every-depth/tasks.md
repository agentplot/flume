# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on main and on the
groups before it. The statement's base places and watch are on
agentplot/blueprints main at 51b6316, and record 0051 accepted, on the
user's approval of 2026-11-06. Its amendment to the user's ruling the
same day that no terminal settles is on main at 6dc9399, record 0051's
amendment proposed until the user's yes; group 3 builds to it. A group's last task runs the checks it
touched through sluice. Every conformance scenario a group adds cites
its clauses as data (106), and the engine's scenarios name no tool
(core.1). No code of the core names a kind, a prefix or a depth to tell
a base place: it reads the kind's shape alone (202; core.53). No code of
the core reads a terminal to decide whether flume runs attended: it
reads the host's watch alone (119, 208; core.13). No terminal profile
and no plugin runs a settle, and herdr's plugin reads flume only at a
person's asking (122; core.13). Groups 1 to 3 and 5 need no other
repository's change. Group 4's kinds profile waits on weir's follow-up
W1 and group 6's submit by name on sluice's follow-up S1 (design,
"Named follow-ups"); a build that finds either not landed stops short
naming it, its other tasks done.
