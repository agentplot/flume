# Tasks

Ten groups, in order, each one implementing session that reads this
change and its own group. A group ends with its checks passing through
sluice (`sluice exec main -- moon run …`), committed by pathspec. Every
scenario a group adds to the conformance suite cites its clauses as data
(clause-coverage spec).
