# Tasks

The groups are headings for reading. Each task names the narrowest check
that shows it done, run as written. No task runs the repository's whole
checks or a group's: the change's verify stage and the merge queue run
those (record 0054). The base is `bolt/flumes-module-writes-its-sources`,
the branch this place was cut from and lands on.

nix reads a git tree's tracked files only, so stage each new file under
`nix/` (`git add <paths>`) before a nix command reads it. The tests reach
no account, no network and no home but a scratch one. A test that names
a store file names it by its `outPath`, as `nix/tests/darwin.nix` does.
