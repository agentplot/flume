# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on main once the
user has accepted record 0020's amendment, and on the groups before it.
A group's last task runs the checks it touched through sluice. Every
conformance scenario a group adds cites its clauses as data (106).
Tests reach no real account and no configuration directory of the
user's. Every git call in a test runs under the scratch environment
`crates/flume/tests/common` gives. An agent in a test is the stand-in
(`crates/flume/tests/profiles/stand-in/`) or the fake, but in the one
live walkthrough of group 4. Every `CLAUDE_CONFIG_DIR`, `projects`
folder, link and host configuration a test names is a scratch one of
the test's own.
