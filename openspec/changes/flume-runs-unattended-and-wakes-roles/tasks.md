# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on the tree
`flume-runs-a-kind-through` landed. A group's last task runs the checks
it touched through sluice; every conformance scenario a group adds
cites its clauses as data (106).
