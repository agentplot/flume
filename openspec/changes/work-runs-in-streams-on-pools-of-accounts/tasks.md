# Tasks

Each group is one session's work for an agent that reads this change
(proposal, design, specs) and its group, and builds on the tree at
c82438a and the groups before it. A group's last task runs the checks it touched through sluice;
every conformance scenario a group adds cites its clauses as data
(106). Tests reach no real account and no configuration directory of
the user's: every git call in a test runs under the scratch environment
`crates/flume/tests/common` gives; an agent in a test is the stand-in
(`crates/flume/tests/profiles/stand-in/`) or the fake; every
`CLAUDE_CONFIG_DIR`, account `env` and host configuration a test names
is a scratch directory or file of the test's own; and a usage limit is
words a test writes, never one a real account met.
